Steam Workshop changelog for Better Colony Commands. Paste the relevant version's section into the "Change Notes" field when publishing that update. Most recent first.

[hr][/hr]

[b]v1.0.16[/b]
[list]
[*] Fixed role tags showing an extra pair of brackets around custom-styled prefixes (e.g. a prefix already written as "[Owner]" no longer becomes "[[Owner]]"). Brackets are now entirely up to what you put in the prefix itself.
[/list]

[b]v1.0.15[/b]
[list]
[*] Fixed the chat format setting being silently ignored if it was added to an existing chatcolors.json without also restructuring the file - it's now recognized either way.
[/list]

[b]v1.0.14[/b]
[list]
[*] Fixed /ban by nickname not working for offline players. Banning by SteamID already worked while offline; nickname lookup now does too.
[/list]

[b]v1.0.13[/b]
[list]
[*] Fixed multi-word player names getting cut off after the first word in several commands, causing "player not found" even though the player existed.
[*] Fixed the colony name blacklist never re-checking a colony that already existed with a bad name before the word was added to the blacklist - it's now caught on the next check.
[/list]

[b]v1.0.12[/b]
[list]
[*] Splitscreen profiles (named like "PlayerName 1") can now be targeted by commands by typing the name as one word, without needing quotes.
[/list]

[b]v1.0.11[/b]
[list]
[*] Added /bcreload - reload every config file live, without a server restart.
[/list]

[b]v1.0.10[/b]
[list]
[*] Fixed a case where the colony name blacklist could get permanently stuck on a bad name if a player's own name was also blacklisted.
[*] Expanded the example colony name blacklist to 75 entries and hardened it against common letter-swap evasion tricks.
[/list]

[b]v1.0.9[/b]
[list]
[*] Fixed /setcolonyname, /groups, /tpa, /tpaccept and /tpadeny not being recognized as commands.
[*] The colony name blacklist now supports full regex patterns instead of plain words.
[*] Colony name corrections are now logged to the server console with the exact rule that triggered.
[/list]

[b]v1.0.8[/b]
[list]
[*] Added /setcolonyname - admins can rename any colony via its nearest banner.
[*] Added an optional colony name blacklist that reverts bad colony names automatically.
[*] Added /tpa, /tpaccept, /tpadeny teleport requests with an accept countdown.
[*] Added /groups to list a player's assigned permission groups.
[*] Chat line layout is now fully configurable via a template string.
[*] Player names shown by other commands (top, online, jail, ban, kick, whisper, trade, war, etc.) now use the same role coloring as live chat.
[*] Fixed jail's "restore previous role on release" setting, which never actually worked before.
[*] Added the ability to grant extra roles while jailed or after release.
[/list]

[b]v1.0.7[/b]
[list]
[*] Maintenance taken over by Kleator from this version onward.
[*] Fixed players losing their playtime/last-seen history after reconnecting, caused by a Colony Survival 0.18.0.0 change (splitscreen support) to how player IDs are formatted.
[*] Declared compatibility with Colony Survival 0.18.0.0.
[/list]

[b]v1.0.6 and earlier[/b]
[list]
[*] See CHANGELOG.md in the source repository for the full history.
[/list]
