[b][u]Better Colony Commands[/u][/b]

Server-side admin, moderation and quality-of-life mod for Colony Survival. Anti-grief protection, a jail system, colony/banner tools, chat customization, teleport requests and a long list of admin commands - built for server owners who want real moderation tools without babysitting the server around the clock.

Maintained by Kleator from version 1.0.7 onward. Originally developed by Adrenalynn, continued through version 1.0.6 by Xell. See Credits below.

[hr][/hr]

[h1]Features[/h1]

[h2]Anti-Grief Protection[/h2]
[list]
[*] Protects colony/banner areas from unwanted building and digging by non-members
[*] Configurable protection range and punishment thresholds (warn, kick, ban, jail) for killing colonists
[*] Custom protection areas independent of banners
[*] Delayed join notice with an optional popup, so new players see the rules even with a collapsed chat
[/list]

[h2]Jail System[/h2]
[list]
[*] Send griefers or rule-breakers to a defined jail area, with automatic release after their time is up
[*] Escape attempts extend jail time automatically
[*] Optionally restores a player's actual prior permission group(s) on release, and can grant/revoke extra groups while jailed or after release
[*] Full jail history log per player
[/list]

[h2]Colony Tools[/h2]
[list]
[*] Admins can rename any colony via its nearest banner, regardless of ownership
[*] Optional regex-based colony name blacklist: automatically reverts a colony name created or renamed to something on the list, with the owner warned in chat and the exact rule logged to console
[*] Purge banners/colonies by inactivity, by player, or in bulk
[*] Colonist-per-colony cap based on player permission tier and difficulty
[/list]

[h2]Chat Customization[/h2]
[list]
[*] Fully configurable chat line layout via a template string with placeholders for name, role tag, roleplay marker and message
[*] Per-permission-group colors and custom role tags/prefixes (support full rich-text markup, icons included)
[*] Role-colored player names used consistently across every command's output, not just live chat
[*] Optional roleplay mode with a togglable [RP] marker and roleplay-specific bans
[/list]

[h2]Player & Admin Utilities[/h2]
[list]
[*] /tpa, /tpaccept, /tpadeny - teleport requests with an accept countdown and request timeout
[*] /groups - see a player's assigned permission groups
[*] /warp, /warpbanner, /warpspawn, /warpplace, travel paths
[*] /top, /mtop - player and colony leaderboards
[*] /ban, /kick, /mute, /killplayer, /killnpcs, /inactive - works for offline players by SteamID or nickname where it makes sense
[*] /trade, /trash, /itemid, /online, /lastseen, /list, /stuck, /serverpop
[*] /war - lightweight player/colony war mode for consenting PvP
[*] /bcreload - reload every config file live, no server restart needed
[/list]

[h1]Configuration[/h1]

All settings live in JSON files under your world's save directory, generated with sensible defaults on first run. Covers anti-grief thresholds, chat colors/format, jail settings, announcements, travel paths and the colony name blacklist. Run [b]/bcreload[/b] after editing to apply changes without restarting the server.
