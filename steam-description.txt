[b][u]Better Colony Commands[/u][/b]

Server-side admin, moderation and QoL mod for Colony Survival: anti-grief protection, a jail system, colony/banner tools, chat customization, teleport requests and a long list of admin commands - real moderation without babysitting the server.

Maintained by Kleator since v1.0.7. Originally by Adrenalynn, continued through v1.0.6 by Xell.

[hr][/hr]

[h1]Features[/h1]

[list]
[*] [b]Anti-Grief:[/b] banner protection, configurable punishment thresholds, popup join notice
[*] [b]Jail:[/b] auto-release, escape attempts extend time, restores prior role(s), full history log
[*] [b]Colony Tools:[/b] admin rename, regex name blacklist with auto-revert, bulk/inactivity purging, colonist cap
[*] [b]Chat:[/b] configurable line layout, per-group colors/role tags, roleplay mode
[*] [b]Utilities:[/b] teleport requests, warps, leaderboards, trade, offline-capable moderation, live config reload
[/list]

[h1]Configuration[/h1]

All settings live in JSON files under your world's save directory, generated with sensible defaults on first run. Covers anti-grief thresholds, chat colors/format, jail settings, announcements, travel paths and the colony name blacklist. Run [b]/bcreload[/b] after editing to apply changes without restarting the server.

[hr][/hr]

[h1]Compatibility[/h1]

Colony Survival 0.15.1.0, 0.15.1.1, 0.18.0.0.
